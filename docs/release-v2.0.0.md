# Mini Mark v2.0.0

墨页 Moye 正式更名为 **Mini Mark**。这一版带来了新的图标与清爽界面，也让图片和自定义工具成为写作的一部分。

## 新功能

- **全新外观：** 炫彩双 M 图标，白底、浅灰分区与清爽蓝色强调色；明暗主题切换平滑过渡。
- **图片插入：** 选择文件、拖入或粘贴图片，支持 PNG、JPEG、GIF、WebP；即时、阅读和分屏视图都能预览。
- **自定义插件：** 导入或编写 JavaScript 插件，处理选中文字、插入内容、统计文档、展示结果，并可随时启停或移除。
- **图片随文档保存：** 已保存文档使用旁边的 `assets` 文件夹；草稿图片内嵌保存，另存为会携带本软件导入的图片。

## 修复与改进

- 未命名文档编号每次启动从 1 开始，跳过当前已占用名称。
- 相同的标题快捷键再按一次，可恢复普通正文。
- 放大查找与替换控件，改善窄窗口和分屏布局。
- 修复长标题换行后与下一行文字重叠的问题。
- 保留多标签、YAML、中文公式、PDF 导出和草稿恢复。

## 下载与升级

- **Windows 10 / 11 x64：** 下载 `MiniMark-Setup-2.0.0-windows-x64.exe`。可覆盖安装到原目录，文档与草稿保留；便携版完整解压后运行 `MiniMark.exe`。
- **macOS 13+：** 下载 `MiniMark-2.0.0-macos-universal.dmg`，支持 Apple Silicon 与 Intel。将 `Mini Mark.app` 放入 Applications；原有草稿会继续恢复。
- 从旧名称升级后，确认新应用中的文档恢复正常，再移除旧的 macOS 应用入口。
- 校验文件：`SHA256SUMS-v2.0.0.txt`。

插件入口位于“更多 → 插件”。仅安装自己编写或信任的源码；当前插件用于文档处理，不提供网络或任意文件访问。

安装包尚未使用 Windows 商业代码签名或 Apple Developer ID 公证，首次运行可能出现系统来源提示。请从本仓库下载并核对校验和，无需关闭系统安全保护。
