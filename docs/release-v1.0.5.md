# 墨页 Moye v1.0.5

修复分屏和侧栏切换时的布局问题。

- 分屏左右两栏固定在编辑区域高度内，源码与阅读内容都可以独立向下滚动。
- 修复隐藏侧栏后工作区落入旧网格列、界面被压缩到 226px 的问题。
- 侧栏切换后主动触发 CodeMirror 重新测量，保证行号、编辑区宽度和滚动位置同步。
- 增加长文档分屏滚动与侧栏切换回归测试。

Windows 使用 `Moye-Setup-1.0.5-windows-x64.exe` 覆盖安装到现有目录，数据目录与快捷方式保持不变。macOS 通用版支持 macOS 13+、Apple Silicon 和 Intel。
