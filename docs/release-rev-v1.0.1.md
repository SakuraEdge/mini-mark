# Mini Mark Rev v1.0.1

- 云文档支持删除文件和文件夹，删除前确认；文件夹中的内容会一并删除。
- 删除后保留已打开的文档并切回本地。云端内容已变化时停止删除，避免误删其他设备的修改。
- 发布名称与安装包统一使用 Rev 版本号。
- 普通更新可在“更多 → 检测更新”中查看和安装，不自动弹窗。
- 从 Rev v1.x 升到 Rev v2.0.0 时提示大版本更新，可关闭提醒。
- 保留自动检测和提醒偏好，旧版本的提醒记录不会影响 Rev 更新。
- Windows 更新沿用原安装位置，保留文档和草稿。

Windows 10 / 11 x64；macOS 13+，支持 Apple Silicon 和 Intel。

macOS 使用 ad-hoc 签名，未使用 Apple Developer ID，也未公证。Windows 包未使用商业代码签名。
