# 墨页 Moye v1.0.2

修复更新检测限流，并让 Windows 新版本直接覆盖原安装目录。

## 修复与改进

- 更新检测改用 GitHub 公开静态清单，附带备用地址，不再依赖 REST API 匿名调用额度。
- 连续检测短暂复用结果，网络失败时明确标注缓存时间；没有缓存时提示检查网络。
- Windows 新增“下载并覆盖更新”，下载可取消，安装包大小与 SHA-256 双重校验，启动安装前再次核对。
- 通过正常的文档保存和退出流程再安装；取消保存即可继续编辑。
- 安装器保留原安装目录，覆盖同名程序文件，安全清理已废弃且未被用户修改的程序文件。
- 桌面与开始菜单快捷方式指向同一个程序；支持自定义 Windows 数据目录。
- 延续 v1.0.1 的平滑标签切换、扁平悬停样式和减少动画支持。

## 安装与升级

- **Windows 10/11 x64：** 下载 `Moye-Setup-1.0.2-windows-x64.exe`。旧版需手动运行这次安装器，之后可在软件内下载覆盖更新。安装时可以选择目录、桌面快捷方式和 `.md` 文件关联。
- **macOS 13+：** 下载 `Moye-1.0.2-macos-universal.dmg`，将应用拖到 Applications 并替换旧版；支持 Apple Silicon 与 Intel。
- 发布页提供便携包与 `SHA256SUMS-v1.0.2.txt`。

Windows 程序文件清理仅依据旧安装清单，并核对旧文件内容。自行新增或修改的文件、`Data`、`Source`、`Backups` 目录保留，不会扫描删除其他位置的文档或旧便携目录。

更新仍需网络连接。发行包尚未使用 Windows 商业代码签名或 Apple Developer ID 公证；尚未完成稳定 1 秒内冷启动验收。
