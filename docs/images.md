# Mini Mark 图片

通过工具栏“插入图片”选择文件，或把图片拖到编辑区、粘贴剪贴板图片。支持 PNG、JPEG、GIF、WebP；每张最多 10 MB，一次最多 10 张。YAML 与阅读模式不提供图片编辑入口。

- 已保存的 Markdown：图片按内容哈希去重，写入文档旁的 `assets/mini-mark-<hash>.<ext>`，正文使用相对路径。
- 未保存草稿、浏览器预览：使用内嵌 data URL，保持草稿自包含。较大的内嵌图片会增加 Markdown 文件和草稿体积；建议先保存文档，再导入大量图片。浏览器草稿还受本地存储配额限制。
- 同一个文档另存到新文件夹时，会复制本软件生成的图片资源；已有图片被外部修改或丢失时停止另存为并提示，不覆盖原文档。
- 即时模式可预览独占一行的图片；光标进入图片行时显示 Markdown 源码。阅读、分屏和 PDF 也显示图片。
- 可输入 HTTPS 图片地址或相对路径，在线图片需要网络。普通 Markdown 图片语法也可直接输入。
- Windows 与 macOS 读取相对路径时限定在当前文档目录内。上级目录或链接路径不作为隐式文件授权。

转移使用相对图片的 Markdown 时，请同时转移其 `assets` 目录；手写的其他相对图片引用仍需自行携带资源。外链图片不自动下载到本地。HTML 导出中的相对路径保留原样，独立携带图片应使用内嵌图片或连同资源目录一起转移。
