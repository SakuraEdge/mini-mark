# Mini Mark v1.0.4

> 历史版本，发布时使用名称“墨页 Moye”。原安装包与校验和保持不变。


修复即时排版编辑器中的上下方向键跳行，并加入源码与阅读实时分屏。

- 统一编辑器行盒高度，标题、代码块和空行之间按方向键逐行移动。
- 保留源码视图的行号、折叠和语法高亮；上下方向键与 Shift 选择不再被装饰后的视觉高度干扰。
- 新增“分屏”视图：左侧源码、右侧阅读，输入后约 90 ms 更新预览。
- 分屏在切换标签时分别保留源码和阅读滚动位置，窄窗口自动改为上下布局。

Windows 使用 `Moye-Setup-1.0.4-windows-x64.exe` 覆盖安装到现有目录，数据目录与桌面/开始菜单快捷方式保持不变。macOS 通用版支持 macOS 13+、Apple Silicon 和 Intel。

安装包仍未完成商业代码签名或 Apple Developer ID 公证，。
