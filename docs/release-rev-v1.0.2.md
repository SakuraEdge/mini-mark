# Mini Mark Rev v1.0.2

- GitHub 登录自动复制完整授权码，并提供“复制授权码”按钮。
- 修复 macOS 创建云仓库、删除云文件时确认窗口不显示的问题。
- 文档标签右键菜单新增重命名，支持未保存的草稿、本地文件和云文档。
- 新建 Markdown 草稿的第一行是 H1 标题时，自动使用标题作为文档名；第一行不是 H1 时保持原名。手动重命名或保存后不再自动改名。

Windows 10 / 11 x64；macOS 13+，支持 Apple Silicon 和 Intel。

Windows 可通过“更多 → 检测更新”覆盖升级，保留原安装位置、文档和草稿。

macOS 使用 ad-hoc 签名，未使用 Apple Developer ID，也未公证。Windows 包未使用商业代码签名。
