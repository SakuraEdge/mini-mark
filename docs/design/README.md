# UI 设计参考

## 文件编码（已通过）

[文件编码交互稿](file-encoding-review.html)使用一份 GBK 示例旧稿。状态栏显示当前查看编码，初始为 UTF-8。「切换为…」试读原始字节，「转换为…」设置下次保存的编码，点「保存示例」后模拟写回。简体中文 Windows 的 ANSI 标为 GBK（CP936），西欧 ANSI 标为 Windows-1252。此稿只处理内置示例。2026-11-20 用户确认该界面，正式实现见 `src/features/encoding/`。

## Android UI 设计参考

2026-11-18 用户确认 `android-approved.html`，采用文档、工作区、云文档、设置四个入口，以及多标签、即时、源码、阅读、分屏和底部编辑栏。实现入口为 `src/features/android/` 和 Android 原生宿主。设计中的示例账号与文档用于审核。

`android-ui.html` 从原设备聊天中的交互设计稿原样保留，包含文档库、编辑器、工作区、云文档、底部更多菜单、`/?` 快捷指令与主页更新窗口。

用户已确认的细节：配色清晰明亮；快捷指令入口用小号 `/?`、无背景，与其他图标一致；编辑器底部有更多入口；主页图标可打开更新窗口。

这是早于最终原生实现的设计参考。演示文件、账号、同步状态、版本号和按钮不代表实际功能完成。原稿使用可选的聊天宿主状态接口和 `data-lucide` 图标占位；直接在普通浏览器打开时，布局与页面切换仍可参考，图标可能缺少宿主提供的渲染。不要把原稿当作可安装 Android APP。

本目录保存长期设计源码。Android 的构建、存储、云文档与验证入口见开发说明。[Android 开发说明](../android-development.md)
