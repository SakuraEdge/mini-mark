# Mini Mark Rev v1.0.4

- Android 启动图标与应用内渐变双 M 图标统一，包含相同的字形、位置和下划线。
- Android 提供文档、工作区、云文档和设置四个入口，支持多标签、即时编辑、源码、阅读、分屏、公式、图片、主题背景和插件。
- Android 支持系统文件保存、文件夹工作区、HTML 运行和 PDF/HTML 导出。
- GitHub 云文档支持登录、MiniMarkDisk 浏览、保存、重命名、删除和冲突处理。

Android 8.0 及以上，需要近期版本的 Android System WebView。APK 沿用此前本地预览版的签名，支持覆盖升级和保留草稿。GitHub 账号跨设备全流程与不同手机输入法仍待实机验收。

Windows 10 / 11 x64。macOS 13 及以上，支持 Apple Silicon 和 Intel。macOS 使用 ad-hoc 签名，Windows 使用现有未商业签名的安装包。
