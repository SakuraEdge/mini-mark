# Mini Mark Rev v1.0.5

- 点击状态栏的编码名称，可用「切换为…」预览旧文件的原始字节，用「转换为…」指定下次保存的编码。支持 UTF-8（含 BOM）、UTF-16 LE/BE、GBK、GB18030 和 Windows-1252。转换前会检查全文能否用目标编码保存。
- 在代码块或表格中第一次按 Ctrl+A 选中当前区域，再按一次选中整篇文档。
- 代码围栏支持下拉选择语言，新围栏沿用上次选择。即时模式下输入 `---` 并回车即可显示分割线。
- Ctrl+F 可打开或关闭查找面板，查找与替换的按钮和提示已中文化。

Android 8.0 及以上，APK 沿用此前的签名，可覆盖升级。Windows 安装器适用于 Windows 10 / 11 x64。macOS 通用包适用于 macOS 13 及以上的 Apple Silicon 和 Intel 设备。macOS 使用 ad-hoc 签名，Windows 安装器未使用商业代码签名。
