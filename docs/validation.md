```powershell

```

测试使用隔离草稿目录，不改写真实用户会话。IME 自动测试仍为合成事件，尚未覆盖全部真实中文输入法。v0.2.0 未重新验收冷启动时间，也不宣称达到稳定 1 秒内启动；大文件压力测试和跨平台构建仍未完成。
