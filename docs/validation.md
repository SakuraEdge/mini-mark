# 验证记录

## v2.0.0

2026-11-05。Mini Mark 品牌、主题、图片和插件大版本。

- 本地生产构建、25 项单元测试、66 项原生存储/更新检查、34 项 Edge 交互测试通过。
- 实际 Windows WebView2 检查图片粘贴、相对资源读取、保存及插件隔离执行；禁止联网、DOM/原生桥不可访问、超时停止、过期编辑拒绝、撤销、启停和恢复均有覆盖。
- 插件源码只有在手动保存检查或执行时运行。运行时使用无同源权限 iframe + Worker；不宣称操作系统进程级隔离或无限内存防护。
- Windows 图片读取改用校验文档身份的资源处理器，避免动态虚拟目录映射未生效；添加非图片文件与目录穿越拒绝测试。
- 保存和另存为保留图片；已保存文档使用哈希命名 assets，草稿内嵌图片；长标题和查找控件修复包含在本版。
- 更新清单同时包含旧版兼容安装器和 MiniMark 安装器地址，要求二者内容校验相同。仓库改名后，新旧静态更新入口均实测可读。
- 发布必须使用通过 Windows 和 macOS Actions 的同一提交构建产物；平台构建、安装器及 macOS 实际 WKWebView/PDF 结果以该工作流为准。
