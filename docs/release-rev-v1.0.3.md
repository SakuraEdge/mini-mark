# Mini Mark Rev v1.0.3

- 侧栏新增“单文档”和“工作区文档”切换。打开文件夹后可浏览目录，展开子文件夹并打开文档。
- 工作区显示所有文件；支持编辑的文本在新标签中打开，不支持的文件与链接仅显示，不自动运行。
- 点击左上角 Mini Mark 图标或名称可打开更新窗口。更新窗口重新排版，并显示当前版本或新版的更新内容。
- 新增主题背景，可导入本地 PNG、JPEG、WebP 图片，调整透明度、暂停使用或移除。背景仅保存在本机，不写入正文或导出文件。

Windows 10 / 11 x64；macOS 13+，支持 Apple Silicon 和 Intel。

Windows 可通过“更多 → 检测更新”覆盖升级，保留原安装位置、文档和草稿。

macOS 使用 ad-hoc 签名，未使用 Apple Developer ID，也未公证。Windows 包未使用商业代码签名。
