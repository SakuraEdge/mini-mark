# Mini Mark v1.0.1

> 历史版本，发布时使用名称“墨页 Moye”。原安装包与校验和保持不变。


在 v1.0.0 正式发布之后推出的界面优化更新。

- 文档标签使用平整、轻量的悬停样式，移除重复文件名的原生方框提示。
- 标签切换保留已有界面元素，选中指示条以 180 ms 平滑移动。
- 正文切换使用 120 ms 轻量淡入；即时、源码、阅读视图的选中状态平滑过渡。
- 支持系统“减少动画”设置，开启后立即切换。
- 保留文件名截断、键盘操作、未保存标记、独立撤销和标签关闭确认。

Windows 与 macOS 的安装方式、文件格式和数据目录不变。本次属于补丁更新，v1.0.0 可通过“更多 → 检测更新”发现新版，不会触发大版本弹窗。

下载 Windows 安装版 / 便携版或 macOS 13+ 通用版。当前软件尚未进行 Windows 商业代码签名或 Apple Developer ID 公证；首次启动可能需要系统确认。校验和见附件。
