# Mini Mark v3.0.0

选中文字更清晰，HTML 也可以直接编辑和运行了。

## 新功能

- **HTML 编辑：** 新建、打开和保存 `.html`、`.htm` 文件，提供 HTML、内嵌 CSS / JavaScript 高亮、行号、查找替换和独立撤销。
- **两种运行方式：** 点击播放按钮，在独立的内置浏览器窗口运行；点击浏览器按钮，调用本地 Google Chrome。运行前先保存，取消保存就取消运行。
- **本地网页资源：** 内置预览支持 HTML 同目录及子目录中的 CSS、JavaScript、图片和字体，窗口内可重新运行。
- **可视化公式编辑器：** 点击公式按钮或空公式处的入口，使用分数、根号、上下标、求和、积分和矩阵模板创建公式，预览后写入 Markdown。也可复制结构化公式到支持的 Word/WPS 版本；实际粘贴结果取决于接收软件。

## 修复

- 修复编辑模式中文字选中范围不明显的问题。亮色和深色主题均采用高对比度选区，代码块、标题和引用中的选中文字也清晰可见。

## 默认应用由你决定

- Windows 安装器新增 HTML 默认应用复选框，默认不勾选。勾选后前往 Windows 设置确认，不会强制替换已有浏览器。
- macOS 不抢占 HTML 文件关联，可在 Mini Mark 应用菜单的“HTML 默认应用…”中主动勾选设置，也可通过 Finder“显示简介”更改。
- 调用 Chrome 不依赖 HTML 默认应用设置。

## 下载与升级

- Windows 10 / 11 x64：`MiniMark-Setup-3.0.0-windows-x64.exe`，或解压便携 ZIP 后运行 `MiniMark.exe`。
- macOS 13+，Apple Silicon / Intel：`MiniMark-3.0.0-macos-universal.dmg` 或 ZIP。
- 覆盖升级保留文档和草稿。校验文件为 `SHA256SUMS-v3.0.0.txt`。

打开 HTML 文件只会编辑源码，不自动执行。只运行自己编写或信任的页面；运行中的页面可以联网。内置预览不开放 Mini Mark 的原生文档接口，不支持访问所在目录之外的本地资源；依赖后端服务的项目仍需其开发服务器。

安装包尚未使用 Windows 商业代码签名或 Apple Developer ID 公证。请从本仓库下载并核对校验和，无需关闭系统安全保护。
